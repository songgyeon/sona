# 소나

필름 한 편을 골라 그 안의 인물로 들어가 사는 앱.

- **필름 만들기** — 세계, 내가 맡을 인물, 캐스트와 서로의 사이를 화면에서 쓴다. 오프닝은 컷·지문·대사를 순서대로 쌓아 만든다.
- **저장** — 만든 필름은 내 필름에 남는다. 개봉한 뒤에도 만든 사람은 고칠 수 있다.
- **링크로 보여 주기** — 필름의 주소를 받은 사람은 그 필름 정보로 바로 와서 들어간다. 목록에는 만든 사람의 것만 나온다.
- **필름에 들어가기** — 제목이 뜨고 오프닝이 흐른다. 내려 읽으면 컷을 넣은 자리에서 화면의 그림이 바뀌고, 끝에 닿으면 그 인물로 말한다. 말을 보낼 때마다 작중 시간이 흐른다.
- **자리 비우기** — 떠났다가 돌아오면 그 사이 캐스트가 보낸 하루가 피드와 먼저 온 연락에 남아 있다.
- 작중 24시간이 첫 하루다.

캐스트가 한 명인 필름도, 서로 아는 여럿이 나오는 필름도 같은 화면에서 만들고 같은 코드로 돈다.

## 올리기

저장소에 올리면 Cloudflare가 `wrangler.jsonc`대로 빌드하고 배포한다. 따로 돌릴 명령은 없다.

주소를 열면 바로 필름을 만들 수 있다. 대화를 하려면 Cloudflare 대시보드에서 이 Worker의 **변수와 시크릿**에 오픈라우터 열쇠를 넣는다.

| 이름 | 무엇 |
|---|---|
| `OPENROUTER_API_KEY` | 오픈라우터 열쇠. 없으면 필름을 만들고 저장하는 데까지만 되고, 화면이 그렇다고 알려 준다 |
| `ACCESS_KEY` | 넣지 않아도 된다. 주소를 잠그고 싶을 때만 넣는다. 넣으면 주소 뒤에 `?k=열쇠`를 붙이거나 첫 화면에서 넣어야 열린다 |

어떤 모델을 부를지는 `wrangler.jsonc`의 `MODEL_ID` 한 곳에 적는다(오픈라우터의 모델 이름 그대로).
저장소(D1)는 첫 배포 때 Cloudflare가 만들고, 표는 Worker가 스스로 만든다.

## 돌려 보기

```
npm install
npm run dev        # http://127.0.0.1:8787
npm test
npm run typecheck
```

로컬에서 `.dev.vars`에 `MODEL_KIND=fake`를 적으면 오픈라우터 열쇠 없이 가짜 모델이 선다. 가짜 모델의 답은 정해진 문장이다.

## 구조

```
shared/    types.ts · rules.ts(시간과 연락의 값) · clock.ts(작중 시간)
           opening.ts(오프닝 읽기, 예전 필름을 지금 모양으로) · draft.ts(만들기 화면의 칸 ↔ 필름)
worker/    index.ts(길) · guard.ts(열쇠, 하루 호출 수) · db.ts · schema.ts(표)
           engine/  films(필름 읽고 쓰기) · images(그림) · turn(입장·한 마디·다시 받기) · talk(답 받기)
                    skip(시간 넘기기) · gap(그 사이의 하루) · ping(먼저 오는 연락) · store
           prompt/  system · cast · scene
           model/   index · openrouter · fake
src/       styles.css(생김새) · poster(포스터, 얼굴, 필름 한 줄) · tabs · icons
           pages/   Home(홈) · Film(필름 정보) · Cast(캐스트 프로필과 피드) · Play(재생)
                    Create(필름 만들기) · Lists(찾기, 이어 살기, 내 필름)
test/      engine/*.test.ts
```

세계 상태(작중 시각, 대화, 피드)는 서버에 있다. 화면은 방문자 표만 들고 다닌다.
시간을 미는 것은 코드뿐이다. 모델은 문장만 쓴다.
오프닝은 필름에 있다(`firstScene.beats`). 오간 말에는 넣지 않는다 — 대사 모델에게는 그 자리에 있던 캐스트에게만 통째로 싣는다.
삶은 들어갈 때의 필름을 들고 간다. 필름을 고쳐도 살고 있던 삶은 그대로다.

## 생김새

틀은 흑백만 쓴다. 색은 디렉터가 올린 그림에서만 나온다.
홈의 맨 위는 영화 포스터 한 장이고, 필름과 컷은 필름 한 줄로 흐른다.
재생 중에는 만드는 사람의 표기(씬 번호 같은 것)를 보이지 않는다. 컷 번호와 「지문」「대사」 같은 말은 필름 만들기 화면에만 나온다.
